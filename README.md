# Indah Christiani Sinaga — Portfolio

Personal portfolio website built to showcase my projects, works, and experience as an Information Systems graduate and web developer.

## About

This portfolio is a place to introduce myself, document projects I have worked on, and share selected works such as articles and writing projects.

The website is built with Laravel and focuses on a clean, personal, and responsive presentation.

## Featured Projects

### CATEMU

A web project designed to help cat owners find nearby places and services that can provide assistance for cats.

**Highlights:**

- Location-based search
- Nearby service and place information
- Categories for different types of services
- CATEMU partner information

### Student Attendance System

A web-based student attendance system using QR Code technology.

**Highlights:**

- QR Code-based attendance
- Student and teacher-related features
- Attendance records
- Attendance recap

### A Birthday in Space

A small creative web project created as a birthday experience.
